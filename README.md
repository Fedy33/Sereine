# Sereine

App web pour futures et jeunes mamans : démarches, aides, garde (avec carte des lieux proches), ma nounou, soutien.

Site : https://fedy33.github.io/sereine/

- `index.html` : l'app (générée par `tools/build_site.py` à partir de la page publiée dans Claude).
- `g/*.json` : lieux d'accueil du jeune enfant par département, tirés du registre officiel des entreprises (recherche-entreprises.api.gouv.fr), sans les personnes travaillant seules.
- Fond de carte : © OpenStreetMap, © CARTO.
